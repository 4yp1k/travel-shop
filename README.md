# ТурМагазин — Лабораторная работа №2

**Тема:** Верстка сайта по макету. Адаптивная верстка  
**Вариант:** 6 — Продажа путёвок на российские курорты

## Страницы

| Страница | Файл | Описание |
|----------|------|----------|
| Главная | `index.html` | Hero, преимущества, популярные туры |
| Каталог | `catalog.html` | Фильтры + сетка туров |
| Карточка тура | `product.html` | Детальная страница товара |
| Корзина | `cart.html` | Корзина + оформление заказа |
| О нас | `about.html` | О компании |
| Контакты | `contacts.html` | Контакты + форма с валидацией |

## Выполненные требования

### Основное задание
- Многостраничный интернет-магазин по тематике варианта
- HTML5-теги (header, nav, main, section, article, footer и др.)
- Валидация полей форм (required, pattern, type=email, minlength)
- **CSS3 transform:** увеличение изображений при hover (`scale`)
- **CSS3 transform:** поворот иконок (`rotate`)
- **transition** — плавные переходы
- **cubic-bezier** — изменение скорости перехода
- Bootstrap 5 (разрешён по условию)
- Адаптив под разные экраны

### Адаптивность (усложнённое)
- Mobile ~320px
- Tablet 768px
- Desktop 1000px+
- Large 1280px+

## Как открыть

Откройте `index.html` в браузере или:

```bash
python -m http.server 8000
```

## Технологии

- HTML5
- CSS3 (transform, transition, media queries)
- Bootstrap 5.3
- Bootstrap Icons
